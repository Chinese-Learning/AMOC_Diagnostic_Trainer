# AMOC Diagnostic Trainer

Interaktiver Diagnosetest für die gesamte AMOC-Vorlesung (Teil 1 und Teil 2), basierend auf den bereitgestellten Vorlesungsfolien, Übungen, Tutorien und Mock Exams.

- Multiple-Choice-Diagnostik über alle Themenbereiche
- zufällige Reihenfolge
- Hinweise werden separat erfasst
- Themenstatistik und Fehleranalyse
- Fortschritt lokal im Browser gespeichert
- Wiederholungsmodus für falsche/unsichere Fragen

Die Anwendung ist als statische Web-App für GitHub Pages aufgebaut.
